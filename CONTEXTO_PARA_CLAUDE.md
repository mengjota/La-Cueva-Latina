## Secciones del sitio
1. **Hero / Inicio** — imagen impactante con fondo madera + llamada a la acción
2. **Menú** — grid de platos con sistema de carrito (generado por JS)
3. **Reservaciones** — formulario dinámico para reservar mesa
4. **Nosotros** — historia del restaurante
5. **Contacto** — datos de contacto + mapa placeholder
