# La Cueva Latina

Template de página web para restaurantes. Construida con HTML, CSS y JavaScript puro.

## Estructura

```
La Cueva Latina/
├── index.html         ← estructura de la página
├── css/
│   └── style.css      ← estilos y diseño
└── js/
    └── main.js        ← lógica del carrito y reservaciones
```

## Stack

- HTML5
- CSS3 (variables, grid, flexbox, animaciones)
- JavaScript vanilla

## Ver el sitio

Abre `index.html` en el navegador, o visita el despliegue en Vercel.
